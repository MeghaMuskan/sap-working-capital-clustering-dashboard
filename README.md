# 📊 SAP Working Capital Clustering Dashboard

> **SAP Business Data Cloud** project for working capital analysis and company-code clustering — aligned with the **Record-to-Report (R2R)** business process domain.

---

## 🧾 Project Overview

This project demonstrates an enterprise-grade business analytics solution built on **SAP Business Data Cloud (BDC)** technologies. It focuses on:

- Analysing **working capital KPIs** across company codes
- Applying **unsupervised clustering techniques** to group company codes based on financial and operational patterns
- Delivering **interactive visual insights** through SAP Analytics Cloud dashboards
- Supporting **data-driven financial decision-making** aligned with the R2R domain

## 🔍 Key Features

### 1. Working Capital Analysis
- KPI tracking across multiple company codes
- Financial metrics aligned with Record-to-Report (R2R) process
- Historical trend analysis for operational efficiency

### 2. Company Code Clustering
- Unsupervised ML clustering to group company codes by financial behavior
- Pattern recognition across working capital metrics
- Cluster-based segmentation to identify performance outliers

### 3. Enterprise Integration
- End-to-end integration across SAP Datasphere, Databricks, and SAP Analytics Cloud
- Scalable architecture suitable for real enterprise datasets
- Follows SAP BDC best practices for data governance

### 4. Interactive Dashboard
- Visual drill-downs by company code, cluster, and KPI
- Built entirely within SAP Analytics Cloud
- Designed for finance and operations stakeholders
